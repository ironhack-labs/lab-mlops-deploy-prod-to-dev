# ML Project: Iris Classification

## Overview
This is a lightweight Machine Learning project demonstrating a basic end-to-end data science workflow. It uses the classic Iris dataset to train a Random Forest Classifier that predicts the species of an Iris flower based on its physical measurements. This serves as a foundational project before moving on to MLOps deployment stages.

## Repository Structure
* `simple_ml_project.ipynb`: The main Jupyter Notebook containing the code for data loading, exploration, model training, and evaluation.
* `requirements.txt`: A list of the Python dependencies required to run the notebook.
* `README.md`: Project documentation.

## Prerequisites
* Python 3.8+ 
* A virtual environment (like `venv` or `conda`)
