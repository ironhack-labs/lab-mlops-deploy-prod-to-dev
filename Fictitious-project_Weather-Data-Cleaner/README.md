# Weather Data Cleaner

This project contains a simple script that:
1. Loads a small fictitious weather dataset
2. Cleans the data (missing values, data types)
3. Displays a statistical summary

## Files
- `weather_cleaner.py`: main script
- `environment.yml`: Conda environment to reproduce the execution

## Installation

### 1. Create the environment
```bash
conda env create -f environment.yml -n project-env
conda activate project-env
